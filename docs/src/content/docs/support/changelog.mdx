## Versioning

`github.com/poli-page/gin` shares its major.minor with the Poli Page API: module `0.13.x` talks to API `0.13`, passes the API contract `v0.13.0`, and requires `github.com/poli-page/sdk-go` `v0.13.0`. Patch numbers are free. A change of the API contract, a new feature, and a raise of the minimum Go or Gin version are each a minor. The module may skip minors when it has nothing to ship for one; there was no `0.12`.
