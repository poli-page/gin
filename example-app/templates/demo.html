Render 01 · instant

Three SDK entry points for rendering the getting-started/welcome template: binary PDF (Render.PDF), streamed PDF (Render.PDFStream), and HTML preview (Render.Preview).

Press a button to render.

Documents 02 · store & retrieve

Persist a render (Render.Document), then fetch it back, preview it, list thumbnails, or soft-delete it. The four right-hand buttons unlock after a document exists.

Filesystem 03 · render to disk

polipage.RenderToFile streams the PDF straight to disk under example-app/output/welcome.pdf — memory-bounded regardless of size.

outputidle
Press the button to stream a PDF to disk.

Error handling 04 · typed errors

Sends a deliberately malformed version string to trigger INVALID_VERSION_FORMAT. The integration's ErrorMiddleware propagates the API code, message, and request-id straight through as JSON.

outputidle
Press the button to see the error payload.

Command line 05 · CLI

The same SDK from the shell. polipage-render ships in cmd/polipage-render/; install or go run directly. Exit codes per docs/cli.md.

$go run ./cmd/polipage-render --project=getting-started \ --template=welcome --template-version=1.0.0 \ --data='{"name":"world"}' -o /tmp/welcome.pdf
$go install github.com/poli-page/gin/cmd/polipage-render@latest
